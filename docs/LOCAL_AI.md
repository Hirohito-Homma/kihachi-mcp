# ローカルAI制作

日常の制作は Cursor を開かず [制作画面](STUDIO.md) を使います。導入と設定は [OLLAMA_SETUP.md](OLLAMA_SETUP.md)。

`preview_local_ai_song(brief)` と `create_song(prompt)` は同じ経路の MCP 入口です。日本語をローカル Ollama に渡し、検証済み制作指示と MIDI 候補を返します。Live は変更しません。

例: 「125 BPM、Dマイナー、96小節の暗いテクノ。前半はハットを少なく、後半で増やす。57小節目からドロップにして」

- 接続先とモデルは設定で変えられます（ローカルURLと導入済みモデルのみ）。
- ダウンロード、有料APIへのフォールバックは行いません。
- 明示されたテンポ・キー・小節・ドロップ開始・スイングは AI が別の値を返しても保持します。
- 「暗い」は低めの音域と短調中心の和声として画面に出します。未対応の指示も残します。
- プレビューの実ノートが Live 適用計画のノートです。既存の `create_midi_plan` へ project_plan だけを渡してもこの候補は入りません。
- 形式検査の合格を「良い曲」とは言いません。
