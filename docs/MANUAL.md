# KIHACHI MUSIC AI マニュアル

## 対象と準備

この配布物は macOS 上のローカル制作画面です。初回は `scripts/インストール.command` を開き、以後は `scripts/kihachi-studio.command` を開きます。`uv` と Python の依存関係が必要です。インストーラーは `uv`、Ollama のモデル、Ableton Live を自動導入しません。有料 API も使用しません。`uv` の導入方法は [QUICKSTART.md](QUICKSTART.md) から確認できます。

Ollama は任意です。導入済みモデルが使える場合は日本語の制作指示を解釈し、動かない場合も規則ベースの解釈で候補を作れます。モデルの設定は [OLLAMA_SETUP.md](OLLAMA_SETUP.md) を参照してください。

## 1曲を完成させる操作

1. 制作画面で「制作指示」に、ジャンル、テンポ、キー、小節数、欲しい楽器やリズムを入力します。例: `128 BPM、Aマイナー、64小節のLiquid Drum & Bass。2ステップのドラム、柔らかいパッド、歌うようなリード。`
2. 「候補を生成」を押し、「指示ごとの反映」と「未対応・矛盾・曖昧」を確認します。明示した値が意図と違う場合は指示を書き直します。
3. 「プロジェクト」で構成と各トラックのノート数を確認し、「AIレビュー」を実行します。修正する場合は BEFORE / AFTER を見て採用し、新しい候補を再承認します。
4. Ableton Live に送る場合は [ABLETON_SETUP.md](ABLETON_SETUP.md) に従って KIHACHI Live Device を設置します。「この候補を承認」→「適用内容を確認」→「この内容でLiveへ適用」の順に進みます。適用は1回だけです。
5. `ABLETON VERIFICATION` を確認します。`FAIL` や `EXTERNAL VERIFICATION REQUIRED` は成功ではありません。部分適用の可能性がある場合、自動再送せず Live の状態と Undo 履歴を確認します。
6. 必要ならエフェクト、MIX、サイドチェイン、マスタリングを各欄の「確認」から進めます。WAV を書き出した後に音圧を測れます。数値は聴感評価ではないため、最後は実際に試聴します。

## 音楽理論とパターンの扱い

キー・モード・コード進行は候補の音高に反映されます。ジャンルごとのドラム型、コードの刻み、ベースの密度、スイングは既定値で、明示した指示が優先されます。たとえば `A minorのTechno` は4つ打ちを基調にし、`D minorのReggae` はワンドロップ、`Liquid Drum & Bass` は2ステップ型を選びます。ジャンル名だけでは固有の完成曲にならないため、希望する拍の位置や旋律の動きも文章で指定し、生成後のノートと試聴で確かめてください。

## 保存と復旧

候補は制作画面の「プロジェクト」から再度開けます。保存先は診断画面で確認でき、`KIHACHI_PROJECT_DIR` で変更できます。元の候補、音源、Live Set を整理・削除する前にバックアップしてください。接続や起動の問題は [TROUBLESHOOTING.md](TROUBLESHOOTING.md)、各画面の説明は [STUDIO_GUIDE.md](STUDIO_GUIDE.md) を参照してください。
