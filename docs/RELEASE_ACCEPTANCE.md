次の実機判定では、採用されたオフラインのマスター試聴版を基準にし、必要ならLive側のマスターチェーンを別途プレビューして承認後に適用する。配布環境も別のMacで確認する。比較用に旧WAVを-14 dB下げた `TEST002Fat-tight-old-level-matched.wav` を作成し、新WAVとIntegrated -21.6 LUFSで揃えた。旧WAVの元のクリップ歪みは消えていない。新WAVはクリップのないミックスで、完成マスターとは判定しない。比較証跡は `outputs/release-test-20261001/test002-wav-comparison.json`。11トラックMIX案（Kick -6 dB、Sub -12 dB、Bass -13 dBなど）は承認後に適用し、11/11操作のフェーダー・パンがLive読戻しと一致した。部分適用した `テストSET` はそのまま保持し、同じ候補を自動再送しない。Kickパッド36は承認後に標準の `kihachi-kick.wav` から `kihachi-kick-fat-tight.wav` へ1操作で差し替え、Liveのサンプルパスを再取得して一致を確認した。これは音質の聴感評価を意味しない。

隔離インストール時は既存Studioがポート8765で動いていたため、`doctor` のStudio・LiveのPASSはその既存プロセスの状態だった。新しいインストール自身の起動成功とは数えない。別途行った `.app` の起動・生成試験はポート18780と隔離データフォルダを使った実プロセスの検証である。
