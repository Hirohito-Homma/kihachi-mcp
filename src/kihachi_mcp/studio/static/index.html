パートの計画

      
上で選んだ役割、キー、テンポ、小節で、この画面の中で計画します。全パートを選ぶと、パートごとにトラックを分けます。承認だけでは Live に送りません。「実機の Live に送る」は、1回目で実機の Set を読んで末尾に置き直し、承認し直したあとの2回目で1回だけ送ります。再生と録音を止めてから押してください。読んだあと15分で期限切れです。同じ名前のトラックがあるときは送りません。保存はしません。

                Liveへ適用
                
      
                パート計画の保留はありません。Liveには送っていません。
                
      
                流れ: 承認 → 適用内容を確認（ドライラン。Liveは変わりません）→ この内容でLiveへ適用 → Liveから読み戻して検証。
                
      
      
      
                
        
        
        
        
        
      
                
      
                
      
                
      
                
      
                

      
                アレンジメントに展開
                
      
                Sessionへ適用済みの候補を、同じ小節位置のままアレンジメントへ複製し、セクションの頭にロケーターを置きます。既存のアレンジメントのクリップは動かしません。再生を止めてから実行してください。
                
      
                
        
        
      
                
      
                
      
                

      
                エフェクト処理
                
      
                適用済みの各トラックの音源の後ろに、パートごとのEQ・コンプ・サチュレーター・リバーブ・ディレイを追加します。既に載っているデバイスは変えず、同じデバイスは二重に入れません。再生を止めてから実行してください。
                
      
                
        
        
      
                
      
                
      
                

      
                エフェクトのつまみを設定し直す
                
      
                選んだパートのエフェクトのつまみを、今のレシピの値に設定し直します。デバイスの追加・削除はしません。トラックにレシピどおりのエフェクトが並んでいないパートは変えません。
                
      
                
      
                
        
        
      
                
      
                
      
                

      
                MIX
                
      
                各トラックの音量(dB)とパンをクラブ向けに揃えます。キックを一番上に、120Hz以下のパートは中央、マスターに約6dBの余裕を残します。音量とパン以外は変えません。
                
      
                
        
        
      
                
      
                
      
                

      
                サイドチェイン（キックで低域を沈める）
                
      
                Sub・Bass・Pad の最後にコンプを追加し、キックが鳴る瞬間だけ音量を下げます。キーはキックのエフェクト後・フェーダー前なので、MIXの音量を変えても効き方は変わりません。既存のデバイスは変えません。
                
      
                
        
        
      
                
      
                
      
                

      
                マスタリング
                
      
                Setのマスタートラックに EQ → Glue Compressor → Saturator → Utility（低域モノ）→ Limiter（True Peak, 天井 -1.2dB）を追加します。マスターに既にあるデバイスは消さず、その後ろに入れます。毎回確認してから送ります。
                
      
      
                
        
        
      
                
      
                
      
                

      
                音圧を測る
                
      
                Live で書き出した WAV / AIFF / FLAC のパスを入れます（Finder でファイルを選んで ⌥⌘C でパスをコピーし、貼り付け）。Live には触れません。選択中の候補があればセクション別にも測ります。
                
      
      
                
        
      
                
      
                
    
                

    
                
      
                適用済みトラックにサンプルを入れる
                
      
                Studioを再起動して候補が消えたときに使います。Liveのトラック名「KIHACHI Kick ababf584 [KIHACHI]」の8桁を入力してください。空の Kick 36 / Hats 42 パッドにだけ入れ、既存のパッドは上書きしません。再生を止めてから押してください。
